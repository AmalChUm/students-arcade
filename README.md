
# Students Arcade

Students Arcade is a Python project that allows students to create and run different plugins.

## Features
- Python-based arcade application
- Student-created plugins
- GitHub Actions for continuous integration
- Automated Python syntax checking
- Continuous delivery workflow for packaging the project

## How to Run
1. Install Python.
2. Download or clone the repository.
3. Open a terminal in the project folder.
4. Run:

   python main.py

## GitHub Actions
The project uses GitHub Actions to check Python code and package the application into a downloadable ZIP file.
